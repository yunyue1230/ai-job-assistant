# 机器学习工程师 — 推荐与排序

## 岗位职责

1. 负责推荐系统召回与排序模型的迭代，覆盖特征、训练、离线评估、线上 A/B 全流程；
2. 搭建特征平台与样本回填流程，解决特征穿越与样本偏差；
3. 负责模型上线与服务化，把 P99 延迟控制在 50ms 以内；
4. 与算法、工程团队共建实验平台，缩短从想法到线上的周期。

## 任职要求

- 3 年以上机器学习工程经验，熟悉 PyTorch，能独立完成模型训练与调优；
- 熟悉推荐系统的基本结构：多路召回、粗排、精排、重排；
- 有特征工程与样本构建经验，理解正负样本采样、负样本漂移；
- 熟悉模型服务化，了解 ONNX、TensorRT、Triton 中的至少一种；
- 熟悉 A/B 实验设计与指标口径，能解释显著性检验的结论；
- 工程能力扎实，Python 熟练，熟悉 Spark 或 Flink 者优先。

## 加分项

- 做过向量召回（双塔、ANN 索引）；
- 有大规模稀疏特征训练经验；
- 熟悉实验平台建设。

## 面试重点

- 会追问「你的离线指标涨了但线上没涨，怎么排查」；
- 会要求手写简单的采样或损失函数；
- 会问特征穿越具体怎么发生的。
