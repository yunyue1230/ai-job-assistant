# 数据分析师 — 增长方向

## 岗位职责

1. 维护增长相关的指标体系，定义并监控注册、激活、留存、付费的漏斗口径；
2. 支持业务方的日常取数与专题分析，输出可落地的结论而不是一堆图表；
3. 设计并分析 A/B 实验，判断策略是否真的有效；
4. 搭建自动化看板，减少重复取数。

## 任职要求

- 2 年以上数据分析经验，SQL 熟练，能用窗口函数、CTE 写复杂的多表关联查询；
- 熟悉常见的统计方法：假设检验、置信区间、样本量估算，能识别辛普森悖论；
- 会用 Python（pandas）或 R 做数据清洗与建模；
- 有 BI 工具使用经验（Tableau、Power BI、Superset 等）；
- 能把分析结论讲清楚，书面表达过关。

## 加分项

- 有增长、留存、LTV 相关分析经验；
- 懂埋点方案设计与数据质量治理；
- 有因果推断（DID、PSM）实践经验。

## 面试会问

- 「留存率下降了 5%，你怎么定位原因」；
- 「实验组涨了但样本量很小，你怎么判断」；
- 现场写一段 SQL：取每个用户最近一次下单的金额。
