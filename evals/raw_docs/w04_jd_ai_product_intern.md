# AI 产品实习生（LLM 应用）

## 关于岗位

我们在做一个面向求职者的 AI 助手，帮助用户改简历、做模拟面试、匹配岗位。团队 6 人，产品 2 人，算法 1 人，全栈 2 人，实习生会直接参与从需求到上线的全过程。

## 你会做的事

1. 参与 LLM 功能的需求分析与原型验证，把模糊想法做成能演示的 demo；
2. 写 prompt、调参数、做小规模对比实验，记录每次改动的效果；
3. 做用户访谈与问卷，整理成可执行的产品结论；
4. 用 SQL 和表格看数据，定位功能的使用情况与流失环节；
5. 写需求文档、评测记录、上线说明。

## 我们需要你

- 计算机、数据科学、信息系统等相关专业在读，每周到岗 4 天以上，实习 6 个月起；
- 会用 Python 写脚本，能调 LLM API，理解 prompt engineering 的基本套路；
- 有基本的数据分析能力，会写 SQL，会用 Excel 或 BI 工具做简单的可视化；
- 沟通清楚，能把技术限制翻译成产品语言；
- 对 AI 产品有真实的使用和判断，不是只看过新闻。

## 加分项

- 自己做过完整的 AI 小项目并上线；
- 有用户研究或增长相关经历；
- 了解 RAG、微调、评测的基本概念。

## 说明

实习生会有独立负责的小模块，也会被拉去做用户访谈和数据清理，重复性工作不少，介意慎投。
