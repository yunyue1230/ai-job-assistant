# 机器学习八股复习（自用）

不写定义，只写「被追问时怎么答」。

## 偏差与方差

高偏差 = 模型没学好（欠拟合），训练集和验证集都差；高方差 = 记住了训练集（过拟合），训练好验证差。

面试常问「怎么判断是过拟合」。我的答法：看训练/验证 gap 随 epoch 的变化趋势，如果验证损失先降后升而训练损失一直降，就是过拟合；如果两条曲线都很高且贴在一起，是欠拟合。

## 正则化

- L1（Lasso）：梯度是常数，会把不重要的权重压到 0，产生稀疏解，可以用来做特征选择。
- L2（Ridge）：梯度与权重成正比，把权重整体压小，不会归零。
- Dropout：训练时随机置零，相当于对子网络做集成；推理时要按保留率缩放，否则期望对不上。
- Early stopping：最便宜的正则，本质是限制模型在参数空间的移动距离。

## BatchNorm 与 LayerNorm

BatchNorm 在 batch 维度上算均值方差，依赖 batch 大小，小 batch 时统计量不稳；训练和推理行为不同（推理用滑动平均）。它让损失曲面更平滑，可以用更大学习率。

LayerNorm 在特征维度上算，不依赖 batch，所以变长序列和 batch=1 都能用，Transformer 里都是它。

有个细节：BatchNorm 在 CV 里通常放在 conv 之后、激活之前；Transformer 的 LN 有 post-LN 和 pre-LN 两种，pre-LN 训练更稳，深层模型基本都用 pre-LN。

## 梯度消失与爆炸

链式法则连乘，深层网络里梯度会指数衰减或放大。

- 缓解消失：换 ReLU 类激活、残差连接、归一化、LSTM 的门控；
- 缓解爆炸：梯度裁剪、调小学习率、权重初始化（Xavier / He）。

初始化要注意配套：ReLU 配 He 初始化（方差 2/n），tanh 配 Xavier（方差 1/n）。

## Transformer

自注意力的计算复杂度是 O(n²·d)，n 是序列长度。所以长文本要么截断、要么用稀疏注意力/线性注意力，要么用检索把长度压下来。

多头的意义是把表示空间切成多个子空间，各自学不同的关系模式，最后拼起来再做线性变换。头数增加但总维度不变时，每个头的维度变小，表达能力和计算量基本不变。

位置编码：绝对位置编码（可学习或正弦）在超出训练长度时外推很差；RoPE 通过旋转把相对位置编码进 q·k，是目前主流；ALiBi 用距离惩罚做偏置，外推更好。

## 类别不平衡

- 重采样：过采样（SMOTE 之类的合成）、欠采样；
- 重加权：给少数类更大 loss 权重，等价于改先验；
- 阈值调整：不改模型，改判定阈值，成本最低；
- 换指标：不平衡时 accuracy 没意义，看 PR 曲线/AUC-PR，或者按业务定 recall 优先还是 precision 优先。

AUC-ROC 在不平衡数据上会偏乐观，因为它看的是 TPR 和 FPR，负样本极多时 FPR 稍微动一点分母很大。所以诈骗检测、罕见病这类场景更常看 AUC-PR。

## 特征泄漏

最常见的三种：

1. 用了预测时刻拿不到的特征（比如用「最终是否退款」预测「是否欺诈」）；
2. 归一化/填充用了全量数据的统计量，而不是只用训练集；
3. 时间序列随机切分，导致未来信息进训练集。

第三条在推荐里就是特征穿越：样本回填时用了 T 时刻之后的特征。排查方法是看特征的时间戳和样本时间戳的关系，做一次「只保留 T 之前特征」的重算，看指标掉多少。

## 离线涨线上不涨

面试高频。我的答法按顺序排：

1. 数据分布不一致（训练集和线上流量的样本偏差）；
2. 特征线上缺失或口径不同（离线有、线上没对齐）；
3. 指标和业务目标不一致（离线 AUC 涨了，但业务看的是 top-10 点击）；
4. 位置偏差、反馈闭环（线上曝光受旧模型影响）；
5. 实验流量太小、周期不够，差异不显著。

先做一次特征一致性校验，再比对离线评测集的样本来源，最后才怀疑模型。
