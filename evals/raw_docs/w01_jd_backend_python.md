# 后端开发工程师（Python）— 跨境电商平台

## 团队与业务

我们负责跨境交易链路的订单与履约服务，日均订单 40 万单，峰值 QPS 6000。团队 12 人，后端 7 人，服务全部运行在 AWS 上，核心链路已容器化。

## 岗位职责

1. 负责订单、库存、履约服务的接口设计与实现，保证下单链路的高可用；
2. 参与核心服务的性能优化，处理慢查询、连接池、缓存击穿等线上问题；
3. 设计异步任务与补偿流程，保证支付回调、发货通知等跨系统调用最终一致；
4. 参与值班与故障复盘，推动监控告警和预案落地。

## 任职要求

- 3 年以上 Python 后端经验，熟悉 FastAPI 或 Django，能独立设计 RESTful 接口；
- 熟悉 PostgreSQL，能读懂执行计划，具备索引设计与慢查询优化经验；
- 熟悉 Redis，理解缓存穿透、击穿、雪崩的成因与应对，了解分布式锁的实现与坑；
- 熟悉 Celery 或其他任务队列，理解消息重投、幂等、死信队列的处理方式；
- 熟悉 Docker，了解 Kubernetes 的基本编排概念；
- 有可观测性建设经验（日志、指标、链路追踪）者优先。

## 加分项

- 有高并发交易系统经验；
- 熟悉 gRPC、Protobuf；
- 有 SLO 定义与容量评估经验。

## 面试流程

技术一面（编码 + 项目）→ 技术二面（系统设计）→ 交叉面 → HR 面。编码题为中等难度，系统设计常考「设计一个下单接口，如何防超卖」。
