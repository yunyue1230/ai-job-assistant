# 平台工程师 / SRE

## 岗位职责

1. 负责公司 Kubernetes 集群的日常运维与容量规划，保障核心服务可用性；
2. 建设 CI/CD 流水线，缩短发布耗时，降低发布风险；
3. 建设监控与告警体系，推动告警收敛，减少无效打扰；
4. 参与故障应急与复盘，输出可执行的改进项；
5. 推动基础设施即代码，逐步把手工操作变成可审计的变更。

## 任职要求

- 3 年以上运维或平台开发经验，熟悉 Linux 与网络基础；
- 熟悉 Kubernetes，理解 Pod、Deployment、Service、Ingress、HPA 的作用与限制；
- 熟悉容器与镜像构建，能优化镜像体积与启动时间；
- 熟悉 Prometheus、Grafana、Loki 一类的可观测性栈；
- 会用 Terraform 或 Ansible 管理基础设施；
- 至少掌握一门脚本语言（Python、Go、Shell）。

## 加分项

- 有大规模集群（500 节点以上）运维经验；
- 熟悉服务网格、灰度发布、混沌工程；
- 有成本优化经验（资源利用率、竞价实例）。
